2026년 9월 17일(목) 19:30 · 메가박스 아트나인 0관 · 92석
현장 티켓 배부용. 노트북 1대 + 외부 모니터(듀얼) 기준.

```
index.html   운영자 화면 + 관람객 화면 (한 파일, ?view=display 로 분기)
Code.gs      구글 시트 백엔드 (Apps Script)
명단.csv     초기 명단 92명 (시트에 한 번 붙여넣는 용도)
vercel.json  정적 배포 설정
```

**개인정보는 index.html에 들어 있지 않습니다.** 명단은 전부 구글 시트에 있고, 앱은 열릴 때 시트에서 읽어옵니다.

---

## 1. 구글 시트 만들기 (5분)

1. 구글 드라이브에서 스프레드시트를 새로 만듭니다. (예: `2026 GV 좌석배정`)
2. 첫 시트의 이름을 **`명단`** 으로 바꿉니다.
3. **파일 → 가져오기 → 업로드**에서 `명단.csv`를 올리고,
   가져오기 위치는 **현재 시트 바꾸기**를 고릅니다.
   → `ID · 성함 · 소속 · 구분` 네 열에 92명이 들어갑니다.

`배정` 시트는 앱이 처음 저장할 때 자동으로 만들어집니다. **그 시트는 앱이 통째로 덮어쓰므로 손대지 마세요.** 명단은 시트에서 직접 고쳐도 되고, 앱 화면에서 고쳐도 됩니다.

## 2. Apps Script 배포 (10분)

1. 그 시트에서 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `Code.gs` 내용을 통째로 붙여넣습니다.
3. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성 `TOKEN` / 값은 아무 문자열 (예: `artnine-0917-7392`) — 복사해 둡니다.
4. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인 → `.../exec` 로 끝나는 **웹 앱 URL** 복사

> "이 앱은 확인되지 않았습니다"가 뜨면 **고급 → (프로젝트 이름)(으)로 이동**. 본인이 만든 스크립트라 정상입니다.

## 현장 사용법

### 시작 전
1. 노트북에서 배포 주소를 엽니다 → **운영자 화면**. 상단 표시등이 초록 "시트 저장 완료"인지 확인.
2. **관람객 화면 열기** → 새 창을 외부 모니터로 끌고 가서 **F11**(전체화면)
3. 테스트로 한 명 배정 → 시트 `배정` 탭에 기록되는지 확인 → **전체 배정 초기화**

### 배부
1. 성함 검색 → 목록에서 선택(Enter로 첫 번째 선택)
2. 배치도에서 빈 좌석 클릭 → 확인 → 배정 완료
3. 관람객 화면에 **성함 + 좌석이 크게** 뜹니다

### 명단 고치기
- **추가**: `참석자 명단` 탭 → `참석자 추가`. 또는 검색 결과가 없을 때 뜨는 `명단에 추가`
- **수정**: 명단 탭의 각 줄 `수정`, 또는 배정 화면에서 그 분을 선택한 뒤 `정보 수정`
- **삭제**: `수정` 창 안의 `삭제`. 좌석이 배정돼 있으면 그 좌석도 함께 취소됩니다
- 전부 구글 시트 `명단` 탭에 곧바로 반영됩니다

### 변경·취소
- **좌석 변경**: 그 분을 선택한 상태에서 다른 빈 좌석 클릭
- **취소**: 선택 후 `배정 취소`, 또는 배치도에서 그 좌석을 눌러 `배정 취소`

### 그 밖에
- `이름 표시`: 배치도 좌석에 성함이 함께 뜹니다. **관람객 화면에도 같이 적용**되니 로비 화면에 성함을 띄우고 싶지 않으면 꺼 두세요(기본 꺼짐).
- `CSV 내려받기`: 참석자순 + 좌석순 두 표가 한 파일로.
- `시트에서 새로고침`: 시트에서 명단을 직접 고쳤을 때, 또는 노트북을 바꿨을 때.

## 알아두실 점

- **첫 실행에는 인터넷이 필요합니다.** 명단을 시트에서 읽어와야 하기 때문입니다. 한 번 읽고 나면 브라우저에 저장되어, 이후에는 끊겨도 배부가 계속됩니다. 그러니 **로비에 가기 전에 반드시 한 번 열어보세요.**
- 배정과 명단 수정은 화면에서 즉시 끝나고, 시트 저장은 뒤따라갑니다. 끊기면 상단이 빨간색이 되고 3초→6초→9초 간격으로 자동 재시도합니다. 저장이 밀린 채 창을 닫으려 하면 브라우저가 한 번 잡아줍니다.
- 관람객 화면과 운영자 화면은 **같은 브라우저의 같은 주소**여야 연결됩니다. 노트북 1대 구성이라 문제없습니다.
- 시크릿 창은 쓰지 마세요. 저장된 명단과 배정이 창을 닫으면 사라집니다.
- 배포 주소를 아는 사람은 명단을 볼 수 있습니다(시트 내용을 앱이 읽어오므로). 행사 전까지 주소를 공유하지 마시고, 끝난 뒤에는 Vercel 프로젝트를 삭제하거나 Apps Script 배포를 보관 처리하시면 됩니다.
